## تفاصيل المرحلة 6.3 — الهيكل العام والمكونات المشتركة (Mobile Navigation + usePublicData)

### 1. ما تم إنجازه
1. **قائمة تنقل متجاوبة للهواتف (RTL Mobile Drawer)**:
   - لوحة منزلقة من اليمين متوافقة مع قراءة اللغة العربية (RTL).
   - زر تحكم Hamburger يتبادل مع أيقونة الإغلاق بسلاسة.
   - خلفية معتمة بصرية (Backdrop) مع دعم النقر للإغلاق.
   - شريط ترويسة يحمل اسم وشعار الصرح القرآني وزر إغلاق مباشر.
2. **إغلاق تلقائي عند الاختيار**:
   - إغلاق القائمة فور النقر على أي رابط قسم.
   - إغلاق القائمة فور النقر على زر دخول البوابات.
   - إغلاق القائمة عند النقر خارجها على الخلفية المعتمة.
3. **دعم إمكانية الوصول الكاملة (A11y & Keyboard)**:
   - دعم مفتاح `Escape` للإغلاق الفوري.
   - قفل تمرير الصفحة في الخلفية (`document.body.style.overflow = 'hidden'`) لمنع التشتت.
   - سمات ARIA كاملة: `aria-expanded`، `aria-controls`، `aria-label`، `role="dialog"`، `aria-modal="true"`.
   - حلقات تركيز بصرية واضحة للوحة المفاتيح (`focus-visible:ring-2`).
4. **خطاف البيانات العامة `usePublicData`**:
   - استعلام آمن لجداول: `school_settings`, `announcements`, `events`, `teachers`, `circles`.
   - استبعاد تام وصارم لكافة الحقول الحساسة (أرقام الهواتف الشخصية، الرواتب، البريد الشخصي، الملاحظات الإدارية).
   - تصفية أمنية مزدوجة (على مستوى الاستعلام وعلى مستوى العميل Defense-in-depth) للمحتوى غير المنشور أو منتهي الصلاحية.
   - إدارة متكاملة لحالات: التحميل `isLoading`، الخطأ `error`، الاتصال الحي `isSupabaseLive`، وبيانات بديلة `Fallbacks` عالية الجودة.
   - منع تكرار الطلبات المتزامنة عبر `isFetchingRef` وتنظيف وإلغاء الاشتراك عند تفريغ المكون (`isCancelled`).
5. **المحافظة التامة على النظام الداخلي**:
   - بقاء `App.tsx` دون أي تعديل أو مساس.
   - الحفاظ على نظام الصلاحيات والمصادقة ولوحة التحكم الإدارية كما هي.
