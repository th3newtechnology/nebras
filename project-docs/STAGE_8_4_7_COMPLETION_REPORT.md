## 1. ملخص المخرجات المنفذة

تم بناء وإنجاز محرك ومنظومة الإشعارات والتنبيهات المدرسية الميدانية المتكاملة لمدرسة نبراس القرآنية بمسجد إبراهيم الخليل، مع العزل الأمني الصارم ودعم الأولويات والربط التلقائي بأحداث المدرسة:

1. **محرك تصنيف وتوجيه التنبيهات الميدانية (Multi-Category Alerts Engine):**
   - دعم 6 تصنيفات أساسية معتمدة:
     - ⚠️ **الغياب (`absence`):** إشعار فوري لولي الأمر عند تغيب الطالب عن جلسة التحفيظ مع تفاصيل الحلقة والتاريخ.
     - 📜 **التقارير (`report`):** إشعار باعتماد وإرسال التقرير الدوري للطالب مع زر معاينة التقرير والطباعة.
     - 📅 **الحصص والجدول (`session`):** إشعار فوري بأي تعديل في الموعد، تغيير القاعة، أو إلغاء حصة مع بيان السبب.
     - 💬 **الرسائل (`message`):** إشعار باستلام رسالة جديدة موجهة مع معاينة وسياق الطالب المعني.
     - 🌟 **الإنجازات (`achievement`):** تهنئة مباركة بختم حزب أو جزء أو اجتياز اختبار إتقان.
     - ⚙️ **النظام (`system`):** التنبيهات الإدارية والعامة للمدرسة.
   - 4 مستويات أولوية: `urgent` (عاجل - وميض أحمر), `high` (مرتفع - أصفر), `normal` (عادي - أخضر زمردي), `low` (منخفض).

2. **قاعدة البيانات وسياسات RLS والمحفزات الآلية (`20261106000017_notifications_and_alerts.sql`):**
   - ترقية وتوسيع جدول `public.notifications` بإضافة:
     - `category TEXT` مع قيد تحقق من التصنيفات الستة.
     - `priority TEXT` مع قيد تحقق من مستويات الأولوية الأربعة.
     - `metadata JSONB` لحفظ معرفات الكيانات (`studentId`, `reportId`, `circleId`, `scheduleId`, `date`).
     - `action_label TEXT` و `read_at TIMESTAMPTZ`.
   - فهارس أداء على: `category` و `priority` و `(user_id, category, is_read)`.
   - سياسات RLS مشددة: عزل التنبيهات بحيث لا يستطيع أي مستخدم قراءة أو تعديل أو حذف أي تنبيه لا يخصه (`user_id = auth.uid()`).
   - 4 محفزات آلية سحابية (PostgreSQL Triggers):
     1. `trg_notification_read_receipt`: توثيق تلقائي لوقت القراءة `read_at = now()`.
     2. `trg_notify_report_sent`: إشعار تلقائي لولي أمر الطالب عند اعتماد المعلم للتقرير وتغيير حالته إلى `sent_to_guardian`.
     3. `trg_notify_schedule_exception`: إشعار تلقائي لأولياء أمور الحلقة والمعلم عند تسجيل أي استثناء بالجدول.
     4. `trg_notify_new_message`: إشعار تلقائي للمستلم فور إدراج رسالة جديدة في جدول `messages`.

3. **الأنواع والخدمة البرمجية (`notificationsService.ts`):**
   - أنواع برمجية شاملة في `types/notifications.types.ts`.
   - خدمة `lib/notificationsService.ts` متكاملة للعمل سحابياً ومحلياً:
     - `fetchUserNotifications`, `createNotification`, `dispatchBulkNotifications`.
     - `markNotificationAsRead`, `markAllNotificationsAsRead`, `deleteNotification`, `clearAllUserNotifications`.
     - `fetchNotificationStats`: إحصائيات الإجمالي، غير المقروء، العاجل، وتوزيع التصنيفات.
   - دوال التوليد السريع للأحداث المدرسية: `notifyAbsence`, `notifyNewReport`, `notifyScheduleException`, `notifyNewMessage`, `notifyAchievement`.

4. **تكامل واجهة المستخدم وسياق التطبيق:**
   - ترقية `context/NotificationContext.tsx`: دعم الإشعارات المصنفة، الأولويات، عدد العواجل `urgentCount`، وقراءة الكل.
   - تطوير مكون القائمة المنسدلة `components/NotificationDropdown.tsx`:

     - تصفية الإشعارات غير المقروءة بضغطة زر.
     - شارات بصرية ملونة وأيقونات مميزة لكل تصنيف ومؤشر وميض للتنبيهات العاجلة.
     - زر إجراء مباشر (`actionLabel`) ينقل المستخدم للشاشة المستهدفة بضغطة واحدة (مثلاً: الانتقال للجدول أو للتقرير أو للمحادثة).
